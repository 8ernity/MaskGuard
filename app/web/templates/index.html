About MaskGuard

Deep Learning Face Mask Detection Vision System

MaskGuard is an end-to-end AI face mask detection system built on deep Convolutional Neural Networks (CNN) with TensorFlow/Keras and OpenCV. It features real-time client webcam analysis, zero YOLO dependencies, strict data hygiene, and tactile claymorphic UI design.

Model: Custom 3-Block CNN (~110,561 trainable parameters)
Input Resolution: 128 × 128 × 3 RGB
Dataset: Kaggle Face Mask Detection ~12K Images (11,792 human faces)
Server: FastAPI + Uvicorn + WebRTC/Canvas Streaming
