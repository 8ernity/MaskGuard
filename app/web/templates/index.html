MaskGuard is an edge-optimized AI vision solution engineered for real-time compliance verification in healthcare facilities, sterile cleanrooms, commercial transport hubs, and high-density industrial workspaces. Unlike legacy approaches reliant on bloated pretrained object detectors (such as YOLO or SSD), MaskGuard utilizes a decoupled two-stage architecture: an ultra-lightweight OpenCV Haar Cascade locator coupled with a custom, mathematically regularized 3-block Convolutional Neural Network (CNN). The entire pipeline operates deterministically offline at 30–60 FPS on standard CPU/GPU edge hardware with zero external cloud dependencies.

Decoupled Two-Stage Inference

Separates the 60 FPS camera canvas rendering from background AI inference. Camera frames are asynchronously sampled at 400px resolution, reducing network overhead by 75% and enabling sub-20ms detection response without browser render stutter.

Zero YOLO / 100% Custom CNN

Constructed strictly from scratch without bloated multi-hundred-megabyte pretrained object detection backbones. Trained directly via supervised backpropagation with Batch Normalization, Dropout (0.5), and Global Average Pooling to prevent overfitting.

Downward Chin-Safe RoI Expansion

Haar cascades bound the upper face (forehead to upper lip). MaskGuard applies symmetrical 1.40× square expansion with downward center offset (+0.12×dim), capturing the complete jawline, mouth, and chin to eliminate false mask predictions on unmasked faces.

Dual-Space Chromatic Skin Filter

Combines YCrCb (Cr: 133–173, Cb: 77–127) and HSV (S ≥ 25) color space envelopes. Rejects achromatic curtains, folded bedsheets, and patterned wallpaper textures (skin ratio < 5%), preventing false detections and history feed flooding.

End-to-End Vision Pipeline Architecture

Sequential Flow Pipeline
01. Frame Ingestion

Capture webcam frame at 640×480. Downscale to 400px offscreen buffer for transmission.

02. Face Localization

Grayscale conversion + OpenCV Haar Cascade frontalface locator with minSize=(50, 50).

03. Chin RoI & Skin Filter

Downward shift (+12%) for full chin/mouth. Dual YCrCb+HSV filter rejects curtains and fabrics.

04. Dynamic CLAHE

LAB color space luminance CLAHE equalization on dim frames (< 95 brightness) to expose shadows.

05. Preprocessing

Convert BGR to RGB, resize to 128×128 target size, and normalize float32 pixel values to [0, 1].

06. CNN Forward Pass

Compiled TensorFlow graph execution across 3 Conv-BN-ReLU-Pool blocks + GAP dense head.

07. Uncertainty Check

Sigmoid posterior calibration: flags |p - 0.50| < 0.10 or conf < threshold as UNCERTAIN.

08. 60 FPS HUD Render

Draw bounding boxes with rounded badges. Spatial tracking dedups history logging (30s window).

Mathematical Formulations & Objective Functions

1. Binary Cross-Entropy Loss
L_BCE = -1/N * Σ [ y_i * ln(p_i) + (1 - y_i) * ln(1 - p_i) ]

Where y_i ∈ {0, 1} denotes ground truth (0 = WithMask, 1 = WithoutMask), and p_i = σ(z) denotes the sigmoid posterior. Optimized using Adam with initial learning rate η = 1e-3.

2. Calibrated Decision with Uncertainty Margin
Class(p) = MASK (p < 0.5 - δ) | UNCERTAIN (|p - 0.5| ≤ δ) | NO MASK (p > 0.5 + δ)

Implements an empirical boundary margin δ = 0.10 around threshold τ = 0.50 to explicitly flag severe camera blur, extreme occlusion, or ambiguous face angles as UNCERTAIN.

3. 2D Spatial Convolution & Receptive Field
S(i,j,m) = Σ_c Σ_u Σ_v X(i+u-1, j+v-1, c) * K(u, v, c, m)

Standard 3×3 spatial convolution with stride S=1 and zero-padding P=1, yielding spatial output dimension O = ⌊(W - K + 2P)/S⌋ + 1 = W.

4. Dual-Space Chromatic Skin Envelope
Skin_ROI = { p ∈ Frame | YCrCb(p) ∈ [133..173, 77..127] ∩ HSV(p)[S] ≥ 25 }

Requires exposed human skin pixels (≥ 5% of candidate box) in both chromatic spaces. Inanimate background objects (curtains, walls) exhibit S < 20 and are cleanly rejected.

Privacy-First Architecture & Ethics Compliance

100% On-Premise Execution

All camera frames are processed exclusively inside local host memory. Zero video feeds or biometric tensors are ever dispatched to external cloud servers.

Zero Facial Identity Storage

MaskGuard identifies only binary mask compliance status. The system does not perform biometric facial recognition, name association, or database fingerprinting.

Zero Data Leakage Audited

Training pipelines feature automated MD5 hash audits that strictly verify complete separation between training, validation, and test images before model compilation.
